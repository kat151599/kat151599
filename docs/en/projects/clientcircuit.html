The problem

Leads, calls, tasks and contact history often live in disconnected parts of the workflow. Moving from an inquiry to a client project risks losing context and attribution.

The solution

Extend open-source Vikunja with CRM entities and an integrated Call Center while retaining its established project and task management interface.

Implemented features

  • CRM profiles, contact people, ownership, statuses and configurable fields.
  • Client timeline with notes, calls, meetings and task changes.
  • Call Center leads, sources, contact logs and status updates.
  • Task lists, Kanban and interactive browser-demo flows.

Technical approach

Vikunja (Go / Vue / TypeScript) · API contracts · Git · automated testing. ClientCircuit is a modification and integration of Vikunja, not a claim to have authored the task-management platform from scratch.

Demo & validation

The public edition uses the authentic Vue interface with a local data adapter. Visitors enter as a fictional demo administrator; records stay browser-local. Unit and browser checks cover task creation, persistence across reloads and sampled CRM/Call Center interactions.

Source, licenses & privacy

Based on open-source Vikunja; the Call Center component draws on Open Cold Dialer. Original component licenses continue to apply. Licensing notice · Corresponding Vue demo source. No operational customer database, server credentials or service configuration is included.
