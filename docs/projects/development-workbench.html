AI Development Workbench

Модифіковане середовище Wove, яке зв'язує LLM-сесію, стан проєкту та справжній термінал із перевіркою виконання.

Використовується в щоденній роботіPortfolio case study

Проблема

Під час AI-assisted розробки доводилося вручну переносити команди, журнали помилок і контекст між чатом та терміналом. Паралельні сесії створювали ризик плутанини зі станами.

Рішення

Налаштовано робочий цикл: конкретна LLM-сесія ↔ конкретний термінал ↔ результати команд ↔ людська перевірка та рішення про прийняття чи відкат.

Реалізовані можливості

  • Зв'язок браузерної LLM-сесії з терміналом.
  • Ізоляція паралельних сесій та ідентифікатори запитів.
  • Відстеження стану виконання і захист від застарілих результатів.
  • Процес перевірки фактичного результату та відкату змін.

Технічний підхід

Модифікація Wove · TypeScript · Electron · React · Node.js · термінал / PowerShell · журналювання. Робота з кодом базується на сторонньому продукті з дотриманням його ліцензій.

Демонстрація та перевірка

У README є зображення фактичного робочого середовища та схема циклу перевірки. Описано обробку request IDs, stale guards і розділення сесій.

Обмеження й приватність

Це не самостійно написаний із нуля редактор і не повністю автономний AI-агент. Початковий Wove та його компоненти мають власні ліцензії; робочий код модифікації приватний.
