## Як я працюю

**Зрозуміти задачу → описати процес → вибрати архітектуру → реалізувати з AI-інструментами → перевірити фактичну поведінку → виправити, впровадити й задокументувати.**

AI допомагає прискорити реалізацію, але я **не позиціоную себе як розробницю, яка вручну пише кожен рядок коду**. Мій внесок — формування вимог, архітектурні рішення, інтеграція, аналіз збоїв, перевірка та доведення результату до використання.

Згенерований код потрібно перевіряти; для систем із підвищеними вимогами до безпеки чи вузькоспеціалізованої логіки може знадобитися незалежний code review. Віддаю перевагу обмеженому за обсягом пілоту із заздалегідь погодженими критеріями приймання, а не обіцянкам «зробити будь-що».
